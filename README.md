# Student Portal

Interview passed student portal for school admissions and after-interview workflows.

## Features

- Student login demo
- Language switcher: Myanmar, Japanese, English, Vietnamese
- Student journey: enrollment procedures, school life, graduation, after graduation
- Student-entered profile information
- School-managed attendance, grades, assignments, notices
- Career, graduation, and alumni update sections

## GitHub Pages

This is a static website. Publish the repository with GitHub Pages using:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/root`

Then open the GitHub Pages URL shown in the repository settings.
